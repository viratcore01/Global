# Global Cinema Opportunity Radar — Official Source Links

**Purpose:** A direct-link directory for every named tool, library, service, model, API, and platform in the Global Cinema Opportunity Radar design report.

**Link policy:** Links point to the project's official website, official documentation, official source repository, or official model page wherever available. They are not tutorial/search-result links. Some projects use GitHub; a project's official repository may instead be hosted elsewhere.

**Important:** “Open source” does not mean every service is self-hostable or free at every usage level. Hosted services, cloud platforms, and proprietary infrastructure are marked accordingly.

## 11. Practical notes before installing

1. **Start with the core pipeline:** source discovery → fetch → extract → validate → SQLite → ntfy notification.
2. **Do not install every item at once.** Add browser automation, OCR, embeddings and LLM ranking only when the basic pipeline is working on real opportunity posts.
3. **Hosted services are not the same as open-source software.** Google Alerts, Groq, Oracle Cloud, Cloudflare R2 and Healthchecks.io are services. Some have free tiers or open-source self-hosted alternatives, but their hosted plans and limits can change.
4. **Respect source access rules.** Check each website's terms and `robots.txt`; do not bypass logins, CAPTCHAs, or explicit anti-automation restrictions. Use only Discord servers where a bot has been invited and granted the required permissions.
5. **Verify model and package licenses before redistribution or commercial use.** A public repository or downloadable model does not automatically grant unrestricted use.
